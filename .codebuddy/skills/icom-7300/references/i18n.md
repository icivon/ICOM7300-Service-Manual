# 三语对照 / 三か国語対照 / Trilingual reference (ZH / JA / EN)

## 语言规则 / 言語規則 / Language rules

- **ZH**：自动识别提问语言（中文 / 日文 / 英文），并用**同一种语言**组织回答。位号、料号、页码、手册原文引用保持原样不翻译。
- **JA**：質問の言語（中国語／日本語／英語）を自動判別し、**同じ言語**で回答します。位番・型番・ページ番号・マニュアル原文は翻訳しません。
- **EN**: Detect the question language (Chinese / Japanese / English) and answer **in that same language**. Designators, part numbers, page numbers and verbatim manual quotes are never translated.
- 若无法判断，默认中文 / 判別できない場合は中国語 / Default to Chinese when undetectable.

### `no_display`

**中文 — 开机无显示 / 不通电**

- 识别词 / 認識語 / aliases: 开机无显示, 黑屏, 不通电, 无法开机
- 可疑区域 / 疑わしい領域 / suspects: 整机供电输入 / 电源稳压链 / DISPLAY UNIT / MAIN UNIT 复位与 FPGA 配置
- 依据 / 根拠 / basis: 依据 §1 供电规格、§2 稳压器标注、§8 电源网络分布与 §3-3 FPGA 上电加载描述，按「外部供电→稳压→显示接口→数字核心」顺序排列；属派生推理。

  1. 先核对外部直流供电与保险丝：规格书要求 13.8 V DC ±15%，测试连接要求 13.8 V/30 A。手册未给出机内测试点正常电压，不要用推断阈值判断。
  2. 若外部供电正常，按 §2 内部视图逐级核对稳压器标注：14V/8V/5V/3R3V 等电源网络在 §8 接线图中分布于各板。
  3. 核对 DISPLAY UNIT 与 MAIN UNIT 之间的连接与显示器件：§5 给出 DS1（LCD）与 J51 等接插件位号，§7 给出板图位置。
  4. 若供电与连接正常，检查 MAIN UNIT 的 CPU/FPGA 上电配置链（FPGA 程序由外部 EEPROM 在开机时加载），对应 §3-3 与 §10 MAIN UNIT 图纸。

**日本語 — 電源を入れても表示されない／通電しない**

- 识别词 / 認識語 / aliases: 電源が入らない, 画面が映らない, 表示されない, 通電しない, 黒画面
- 可疑区域 / 疑わしい領域 / suspects: 本体電源入力 / 電源レギュレータ系 / DISPLAY UNIT / MAIN UNIT リセット／FPGA 構成
- 依据 / 根拠 / basis: §1 の電源仕様、§2 のレギュレータ表記、§8 の電源ネット配置、§3-3 の FPGA 起動時ロードの記述に基づき、「外部電源→レギュレータ→表示インターフェース→デジタルコア」の順に配置した派生推論です。

  1. 最初に外部 DC 電源とヒューズを確認します。仕様は 13.8 V DC ±15%、試験接続は 13.8 V/30 A です。機内テストポイントの正常電圧はマニュアルに記載がないため、推定したしきい値で判定しないでください。
  2. 外部電源が正常なら、§2 の内部ビューに従ってレギュレータ表記を順に確認します。14V/8V/5V/3R3V 等の電源ネットは §8 の配線図に示されています。
  3. DISPLAY UNIT と MAIN UNIT 間の接続および表示デバイスを確認します。§5 に DS1（LCD）や J51 等の位番、§7 に基板図があります。
  4. 電源・接続が正常なら、MAIN UNIT の CPU/FPGA 起動時構成を確認します（FPGA プログラムは電源投入時に外部 EEPROM からロード）。§3-3 と §10 MAIN UNIT を参照。

**English — No display / does not power on**

- 识别词 / 認識語 / aliases: no display, won't power on, dead, black screen
- 可疑区域 / 疑わしい領域 / suspects: DC supply input / Regulator chain / DISPLAY UNIT / MAIN UNIT reset / FPGA configuration
- 依据 / 根拠 / basis: Derived from SECTION 1 supply specs, SECTION 2 regulator labels, SECTION 8 power-net distribution and SECTION 3-3 FPGA boot loading; ordered external supply -> regulators -> display interface -> digital core.

  1. Check the external DC supply and fuses first: the spec requires 13.8 V DC +/-15% and the test setup 13.8 V/30 A. The manual gives no internal test-point voltages, so do not apply assumed thresholds.
  2. If the supply is good, follow the regulator labels in SECTION 2. Power nets 14V/8V/5V/3R3V are distributed across boards in the SECTION 8 wiring diagram.
  3. Check the DISPLAY-to-MAIN connection and display devices: SECTION 5 lists DS1 (LCD) and connectors such as J51; SECTION 7 gives board layouts.
  4. If supply and connections are good, inspect the MAIN UNIT CPU/FPGA boot configuration (the FPGA loads its program from an external EEPROM at power-on); see SECTION 3-3 and the SECTION 10 MAIN UNIT sheets.

### `low_tx_power`

**中文 — 发射功率低**

- 识别词 / 認識語 / aliases: 发射功率低, 功率上不去, 输出功率小
- 可疑区域 / 疑わしい領域 / suspects: PA UNIT 功放 / PA UNIT 驱动级 / RF UNIT 增益控制/YGR AMP / ALC 与功率检测 / TUNER UNIT 与天馈
- 依据 / 根拠 / basis: 依据 §3-1/§3-2 发射信号链（RF 增益→驱动→功放→LPF→检波→天调）与 §4 功率调整目标值，按由外到内、由后级到前级排列；属派生推理。

  1. 先排除天馈与假负载：§4 要求 50 Ω 假负载/功率计，HF 100% 档调整目标为 105 W（§4-4 原文）。
  2. 沿 TX 信号链向后核对 PA UNIT：驱动级 Q121、推挽功放 Q131/Q132，§3-1 说明功放输出可达 100 W（HF/50 MHz）。
  3. 核对前向/反射波检测与 ALC 环路：D961/D962 检波、IC981 缓冲后送 MAIN UNIT CPU 监控；误动作会压低驱动。
  4. 核对 RF UNIT 侧增益控制（D1051/D1052）与 YGR AMP（IC1031），以及 §4-3/§4-4 的 TX IDLING / TX POWER 调整项，最后查 §10 PA UNIT 图纸。

**日本語 — 送信出力が低い**

- 识别词 / 認識語 / aliases: 送信出力が低い, 出力が出ない, パワーが上がらない, 送信電力低下
- 可疑区域 / 疑わしい領域 / suspects: PA UNIT 電力増幅段 / PA UNIT ドライブ段 / RF UNIT 利得制御／YGR AMP / ALC と電力検出 / TUNER UNIT とアンテナ系
- 依据 / 根拠 / basis: §3-1/§3-2 の送信信号経路（RF 利得→ドライブ→電力増幅→LPF→検波→チューナー）と §4 の電力調整目標値に基づき、外部から内部、後段から前段の順に配置した派生推論です。

  1. 最初にアンテナ系とダミーロードを切り分けます。§4 は 50 Ω ダミーロード／電力計を要求し、HF 100% の調整目標は 105 W です（§4-4）。
  2. TX 信号経路を後段から確認します。PA UNIT のドライブ段 Q121、プッシュプル電力増幅 Q131/Q132。§3-1 では HF/50 MHz で 100 W まで増幅と記載されています。
  3. 進行波／反射波検出と ALC ループを確認します。D961/D962 で検波し、IC981 のバッファ経由で MAIN UNIT の CPU が監視します。誤動作はドライブレベルを下げます。
  4. RF UNIT の利得制御（D1051/D1052）と YGR AMP（IC1031）、§4-3/§4-4 の TX IDLING／TX POWER 調整項目を確認し、最後に §10 の PA UNIT 回路図を参照します。

**English — Low transmit power**

- 识别词 / 認識語 / aliases: low power, low tx output, low tx power, reduced output power
- 可疑区域 / 疑わしい領域 / suspects: PA UNIT power amplifier / PA UNIT driver / RF UNIT gain control / YGR amp / ALC and power detection / TUNER UNIT and antenna feed
- 依据 / 根拠 / basis: Derived from the SECTION 3-1/3-2 transmit chain (RF gain -> driver -> PA -> LPF -> detector -> tuner) and SECTION 4 power targets; ordered outside-in and from the output stage backwards.

  1. Rule out the antenna feed and dummy load first: SECTION 4 requires a 50 ohm dummy load / power meter; the HF 100% target is 105 W (SECTION 4-4).
  2. Work backwards along the TX chain in the PA UNIT: driver Q121 and push-pull PA Q131/Q132. SECTION 3-1 states up to 100 W on HF/50 MHz.
  3. Check forward/reflected wave detection and the ALC loop: D961/D962 detect, IC981 buffers, and the MAIN UNIT CPU monitors. A false action reduces drive.
  4. Check RF UNIT gain control (D1051/D1052), the YGR amp (IC1031) and the SECTION 4-3/4-4 TX IDLING / TX POWER adjustments; finish with the SECTION 10 PA UNIT sheets.

- 依据 / 根拠 / basis: Derived from SECTION 3-3 transmit processing and the SECTION 3-1/3-2 transmit RF chain, tracing the signal from MIC to antenna.

  4. Check the PA UNIT driver/amplifier and LPF relay selection, then verify the SECTION 4-3/4-4 TX IDLING and TX POWER adjustment menus.

### `no_rx`

**中文 — 完全无接收**

- 识别词 / 認識語 / aliases: 无接收, 收不到信号, 静噪
- 可疑区域 / 疑わしい領域 / suspects: RX 静音开关 / RF UNIT 滤波器选通 / A/D 与 FPGA / DSP 解调 / AF 输出级
- 依据 / 根拠 / basis: 依据 §3-2/§3-3 接收信号链按信号流向逐段二分；无接收与灵敏度低的区别在于优先检查静音/选通/数字核心而非前端增益；属派生推理。

  1. 沿 RX 链从天线端确认：§3-2 指出接收信号经 RX mute switch（D1001）与波段滤波器才到前放。

  3. 核对 DSP（IC901）解调与 D/A（IC991）之后的 AF 放大链（IC992、IC721）。
  4. 核对扬声器 LPF 与 speaker SW（Q746）；外接 [EXT-SP] 插入时会断开机内扬声器。

**English — No reception at all**
