# IC-7300 维修辅助回答纪律

适用于本项目所有涉及 IC-7300 维修、元件、参数、页码的问答，无论是否触发 Skill。

## 取证（回答前必须做）

- 先运行 `.codebuddy/skills/icom-7300/scripts/query.py`（Windows 用 `py -3`，其它平台用 `python3`）取到位号、料号、页码与 `coverage`。
- `references/*.md` 只是摘要，不能作为位号、料号、页码或数值的唯一依据。
- 若已注册 MCP Server，可用 `lookup_component` 等工具，结果自带 `citations`。

## 硬性约束

1. 每个数值必须带 PDF 物理页码与原文短引用；无页码不得出现数值。
2. `coverage=not_in_manual` 时明确回答「手册未覆盖」，严禁用经验值、推断值或通用机型数据填补。
3. `coverage=derived` 的故障树不得表述为「手册建议」。
4. `14V` / `3R3V` 等是电源网络标签，标称值由名称推断，不是实测电压，也不是允差。
5. 位号精确等值：`Q1001` ≠ `Q1002`；`DS1`、`R1`、`J1` 等跨板复用位号必须带板名。
6. `[#03, 05, 06]` 是硬件版本标记，不是板名。
7. `query.py userdata` 返回的是 `coverage=user_supplied`，必须标注来源与测量日期，不得表述为手册数据；该文件不存在时，对应项目仍须回答「手册未覆盖」。

## 回答格式

- 自动识别中文 / 日文 / 英文，并用同一种语言回答；位号、料号、板名、页码、手册原文不翻译。
- 结构：可疑区域 → 电路模块 → 关键位号与页码 → 排查步骤 → 数据来源与 `coverage` → 手册未覆盖项。
- 结尾附免责：本 Skill 仅提供技术参考，不构成维修结论；实际故障请自行判断。
